ИИ-Хаб: статический сайт (HTML + CSS + JS, без сборки).

Проверить локально: открой index.html в браузере (двойной клик).
Деплой: загрузи содержимое папки на Netlify Drop, Vercel, GitHub Pages или обычный хостинг. Корнем должен быть index.html.

Что настроить: в js/app.js вверху две ссылки BOT_URL (твой Telegram-бот) и PAY_URL (оплата Rollypay).
Выдачу файла после оплаты настраивай на стороне бота или платёжки.
